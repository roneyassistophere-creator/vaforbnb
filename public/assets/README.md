# Video Assets Folder

Place your video file in this directory:
`g:\02. ASSISTOPHERE\02. ASSIST BNB\assist-bnb\public\assets\`

Supported filename recommendations:
- `hero-video.mp4` (or any `.mp4` / `.webm` / `.mov` file)

When placed here, Next.js can serve it directly to the browser at:
`/assets/<your-video-filename>`
